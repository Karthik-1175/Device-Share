# Device-Share
A console-based device sharing platform developed using Java and Object-Oriented Programming principles that enables users to list, request, approve, borrow, and return devices within a community. The system incorporates authentication, validation, request management operations to ensure a smooth and secure sharing experience.

Device Share System is a Java-based console application designed to simplify the process of sharing devices among users. The application follows a structured workflow where device owners can publish devices for sharing, while other users can submit borrowing requests. Device owners can review and approve or reject requests before granting access.

The system incorporates authentication, validation, request management, device lifecycle tracking, and role-based operations to ensure a smooth and secure sharing experience.

This project serves as a practical implementation of Core Java concepts, Object-Oriented Programming, Interfaces, Enums, Exception Handling, and Package Organization.
